# data/raw_data — 회계기준서 원본 PDF

> **한 줄 요약(BLUF):** 이 폴더의 기준서 PDF는 리포지토리에 포함하지 않는다. 각자 한국회계기준원(KASB)에서 직접 다운로드해 아래 파일명 그대로 이 폴더에 넣는다.

`근거:` 기준서 원문의 배포 주체는 한국회계기준원이므로, 원본 PDF는 각 사용자가 출처에서 직접 받는 것을 원칙으로 한다. 이에 따라 PDF는 `.gitignore`(`data/raw_data/*.pdf`) 처리되어 git에 올라가지 않는다.
